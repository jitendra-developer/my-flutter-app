[BUILD 2.0.0] — Backend Migration (Custom API)
Date: ~2026-03-11
--------------------------------------------------------------------------------
NEW FEATURES:
  - Full migration from Supabase + OpenAI direct calls to custom backend API
  - Base URL: https://api.vakyapro.com/api
  - Authentication via JWT Bearer tokens (login, register, Google OAuth, OTP verify)
  - Chat sessions saved and loaded from backend (/chat-sessions endpoints)
  - AI chat routed through /ai/chat backend endpoint
  - Image generation routed through /ai/image backend endpoint
  - Prompt generation via /prompts/generate endpoint
  - User profile management via /profile endpoint
  - Logout clears local token and calls backend logout

BUG FIXES:
  - Removed all direct Supabase and OpenAI SDK dependencies
  - Resolved auth token handling across app restarts

--------------------------------------------------------------------------------
[BUILD 2.1.0] — Chat Input & Message Display Improvements
Date: 2026-03-12
--------------------------------------------------------------------------------
NEW FEATURES:
  - Mic → Send button transformation:
      * When text field is empty → shows microphone icon
      * When user starts typing → icon smoothly changes to send (↑) arrow
      * After message is sent → reverts back to microphone icon
      * Same purple gradient color palette maintained throughout

  - AI prompt response now shown in a copyable code block:
      * Code block has a dark header bar labeled "prompt"
      * One-tap "Copy" button in the top-right of the code block
      * Animates to "✓ Copied" for 2 seconds after copying
      * Prompt text is selectable (long-press to select manually)
      * Vertical scrolling layout — no more horizontal scroll

  - System prompt updated to enforce code fence format:
      * AI now always wraps the final generated prompt in triple backticks
      * Previous behaviour was wrapping in double quotes

BUG FIXES:
  - Fixed icon not updating when text was typed (missing setState in onChanged)
  - Fixed long prompts displaying as a single horizontal scroll line
  - Added markdown package explicitly to pubspec.yaml for custom builder

[BUILD 2.1.1] — API Docs Compliance & Responsive UI
Date: 2026-03-12
--------------------------------------------------------------------------------
NEW FEATURES & IMPROVEMENTS:
  - Updated logout logic to navigate directly to the Login page instead of the Welcome screen
  - Added `Accept: application/json` header to all API requests to ensure proper JSON responses
  - Reworked ChatSession model to separate local temporary UUIDs from backend numeric IDs
  - Implemented proper create-then-update flow for saving chat sessions to backend `/chat-sessions`
  - Updated messages sent to backend to use proper `{ "role", "content" }` format
  - Optimized Chat Page UI to be fully responsive across all screen sizes (phones, tablets)
  - Made the "Prompt Types" grid dynamically change columns based on screen width
  - Constrained Chat Bubbles to a maximum width of 600px for better readability on tablets
  - Wrapped ChatInputField in SafeArea to prevent overlap with iOS/Android system gesture bars
  - Adjusted ChatInputField and attachments row constraints to prevent overflow on very narrow screens

BUG FIXES:
  - Fixed critical issue where chat saves were failing with 404s and creating duplicates due to using local UUIDs for backend routes
